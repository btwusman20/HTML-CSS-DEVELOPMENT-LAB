Pushing and Cloning a Repository

HTML & CSS Development Lab (BCS554)

Step 1: Bare Remote Setup

A bare repository holds the repository's history and branches without a working directory, making it safe for pushing from multiple clients.

git init --bare ../html-remote
git remote add origin ../html-remote
git remote -v

Step 2: Pushing to Origin

Local commits are pushed to the remote repository on GitHub or the local bare origin.

git push origin main

Step 3: Cloning the Repository

Cloning replicates the remote repository into a new workspace with all history preserved.

cd ..
git clone html-remote html-copy
cd html-copy
git log --oneline
