## 📑 Lab Index &amp; Topics

| Lab No. | Topic / Assignment Title | Core Concepts Covered | Folder Link |
|:---:|:---|:---|:---:|
| **Lab 1** | Starting a Git Repository | `git init`, `git config --local`, `git add`, `git commit`, `git log --oneline` | [View Lab 1](./Lab1/) |
| **Lab 2** | Pushing and Cloning a Repository | Bare repositories (`git init --bare`), `git remote`, `git push origin main`, `git clone` | [View Lab 2](./Lab2/) |
| **Lab 3** | Your First HTML Page | Document structure, page titles, headings (`h1`–`h3`), paragraphs, `strong`, `em`, `br` | [View Lab 3](./Lab3/) |
| **Lab 4** | Divs, Attributes and a Small Fix | Block division (`div`), classes, unique IDs, custom `data-*` attributes, fixing malformed HTML | [View Lab 4](./Lab4/) |
| **Lab 5** | Links and Images | Anchor links (`<a>`), relative paths, image embedding (`<img>`), dimensions, accessibility `alt` | [View Lab 5](./Lab5/) |
| **Lab 6** | Types of HTML Lists | Unordered lists (`<ul>`), ordered lists (`<ol>`), nested lists, description lists (`<dl>`, `<dt>`, `<dd>`) | [View Lab 6](./Lab6/) |
| **Lab 7** | About Me Page | HTML5 semantic sectioning (`header`, `nav`, `main`, `section`, `footer`), `#` anchor jumps, `mailto:` | [View Lab 7](./Lab7/) |
| **Lab 8** | Sign-Up Forms and Choices | HTML forms, `post` method, field labels with `for`, inputs (`text`, `email`, `password`), radio buttons, dropdowns, `required` validation | [View Lab 8](./Lab8/) |
| **Lab 9** | Tables with Headers and Footers | Tables (`table`, `caption`, `thead`, `tbody`, `tfoot`, `tr`, `th`, `td`), column & row `scope` attributes | [View Lab 9](./Lab9/) |
| **Lab 10** | CSS Fundamentals | Inline CSS, internal `<style>` blocks, external stylesheets (`link`), element, class, and ID selectors | [View Lab 10](./Lab10/) |
| **Lab 11** | Units and CSS Variables | CSS length units (`px`, `%`, `rem`), `:root` custom properties, `var()` function, design tokens | [View Lab 11](./Lab11/) |
| **Lab 12** | Box Model, Cards and Scrolling | CSS Box Model, `content-box` vs `border-box`, card component styling (`border-radius`, `padding`), scrollable overflow | [View Lab 12](./Lab12/) |
| **Lab 13** | Flexbox Layouts | Flexible Box Layout, flex container, `gap`, horizontal navigation, `justify-content`, `align-items`, `flex-wrap` | [View Lab 13](./Lab13/) |
| **Lab 14** | CSS Grid Layouts | CSS Grid, `repeat()`, fractional units (`fr`), responsive autofill with `minmax()`, `grid-template-areas` | [View Lab 14](./Lab14/) |
| **Lab 15** | Responsive Pages with Media Queries | Viewport meta tag, Mobile-first design, `@media (min-width: 600px)`, fluid responsive images, scalable typography | [View Lab 15](./Lab15/) |

## 💻 Running the Code

1. **Clone the repository:**
   ```bash
   git clone https://github.com/btwusman20/HTML-CSS-DEVELOPMENT-LAB.git
   cd HTML-CSS-DEVELOPMENT-LAB
   ```

2. **Open any Lab:**
   Navigate to the desired lab folder (e.g., `Lab1/`, `Lab7/`, `Lab15/`) and open `index.html` in any web browser:
   ```bash
   # On Windows
   start Lab1/index.html
   ```
