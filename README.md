# HTML-CSS-DEVELOPMENT-LAB
HTML &amp; HTML & CSS Development Lab

This repository contains practical assignments and projects developed as part of the HTML & CSS Development Lab for B.Tech Computer Science Engineering.

It covers the fundamentals of web development using HTML5 and CSS3, including webpage structure, text formatting, lists, tables, forms, hyperlinks, images, layouts, styling, and responsive web design.

Topics Covered

- HTML5 Fundamentals and Semantic Elements
- CSS3 Styling and Selectors
- Tables, Lists, and Forms
- Images, Hyperlinks, and Multimedia
- Box Model and Positioning
- Flexbox and Grid Layout
- Responsive Web Design
- Practical Web Development Assignments

Technologies Used

- HTML5
- CSS3
- Visual Studio Code

Purpose: To develop practical frontend development skills and understand the fundamentals of designing and building structured, attractive, and responsive web pages.
